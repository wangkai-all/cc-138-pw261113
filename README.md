# 股权台账（Cap Table）

从初始股东开始，逐笔录入 **增资发行 / 股权转让 / 拆股并股 / 注销减资**，可在任意一笔交易之后的时点查看各股东持股数与比例，点击比例回溯构成它的交易。内置融资试算，支持期权池融资前/后补足两种口径对照，试算可另存情景，明确确认后才并入正式台账。

## 运行

```bash
npm start          # http://localhost:3000 （PORT 环境变量可改端口）
npm test           # 领域层单元测试（node:test，无第三方依赖）
```

数据持久化在 `data/ledger.json`（已 gitignore，原子写入）。`DATA_FILE` 环境变量可改路径。

## 规则与不变量

- **转让只改变持有人**，总股本不变；**增资才改变分母**；**拆股/并股同比调整全体股东**，任一持股不能整除即拒绝。
- 股数一律为**整数**（BigInt）；货币与每股价格用**精确小数**（BigInt 尾数 + 标度，除法按 6 位标度四舍五入）。
- 追加式台账：新交易默认追加到末尾，也可插入中间——插入后**整条链重放校验**，凡导致后续交易失效（余额不足、日期倒退）即整体拒绝，**不会产生负持股**。
- 比例 = 持股 ÷ 当时总股本，按 6 位小数四舍五入**显示**；显示值合计可能 ≠ 100%（页面如实标注尾差），**绝不做凑整**。
- 情景并入的交易不可单独撤销；已并入的情景不可删除。

## 融资试算

输入投前估值、投资额、期权池目标（投后 %），选择池在**融资前**（计入投前，原股东承担稀释）还是**融资后**（全员含新投资人共同稀释）补足，两种口径对照输出。每股价格保留 6 位小数，股数向下取整：

- **实际认购额 = 股数 × 每股价格**，与投资额之间的**尾差如实展示**，投资额不被静默修改；
- 池缺口按 `(P0+P)/(S+I+P) ≥ t` 的最小整数 P 精确求解（融资前口径下价格与池规模互相依赖，用单调不动点迭代收敛）。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state?at=N` | 台账全量状态 + 截至第 N 笔的持股表 |
| GET | `/api/provenance?holder=ID&at=N` | 某股东的持股构成（逐笔交易） |
| POST | `/api/transactions` | 录入交易（`insertAfter` 可指定插入位置） |
| POST | `/api/transactions/undo-last` | 撤销最后一笔 |
| POST | `/api/simulate` | 融资试算（两种池口径对照） |
| POST | `/api/scenarios` | 试算另存情景 |
| POST | `/api/scenarios/:id/apply` | 确认并入正式台账（需 `confirm:true`） |
| POST | `/api/sample/load` · `/api/reset` | 载入内置多轮样本 / 清空重置（均需确认） |

## 结构

```
public/        index.html / app.js / styles.css（原生 SPA，无构建）
test/          领域层单元测试
```
